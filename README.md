# Electric Vehicle Market Performance & Insights (Tableau)

Interactive Tableau dashboard analysing EV sales, manufacturers, battery technology,
driving range, manufacturing countries and customer ratings.

## Personas served
- **Emily Johnson (Market Strategy Director):** sales by category, range comparison, growth segments
- **David Chen (BI Manager):** manufacturer market share, battery distribution, country analysis, ratings
- **Dr. Sarah Williams (Researcher):** battery tech comparison, range trends, global manufacturing

## Data
`ev_market_data.csv` – 2023-2025, 16 manufacturers (illustrative/synthetic data).
Columns: Manufacturer, Model, Category, Battery_Type, Manufacturing_Country, Year,
Annual_Sales, Battery_Capacity_kWh, Range_km, Customer_Rating.

## Architecture
CSV/Google Drive -> Tableau Desktop/Public -> Dashboard -> Tableau Public -> End user
